    Create SFTPTransferFooter.swift in MobaAlt/Views/SFTP/:
    - Struct SFTPTransferFooter: View. Takes service: SFTPBrowserService.
    - Computed var activeTransfers: [TransferTask] { service.transfers.filter { if case .completed = $0.status { return false }; if case .failed = $0.status { return false }; return true } }
    - If activeTransfers is empty: show nothing (EmptyView / zero-height frame).
    - If activeTransfers.count == 1: show a single-line footer: filename truncated + ProgressView(value: fraction, total: 1.0). Height ~32pt. Background Color(nsColor: .windowBackgroundColor). Subtle top Divider().
    - If activeTransfers.count > 1: show a ScrollView(.vertical) capped at 3 rows visible (frame(maxHeight: 96)) with one row per active transfer (filename + fraction ProgressView). Plus a "N transfers" summary line below.
    - ProgressView uses .progressViewStyle(.linear). Accentuate with .tint(.accentColor).
    - Extract fractionCompleted from status: if case .inProgress(let f) = transfer.status { return f } else { return 0 }.
    - Register in Xcode project.

    Create SFTPDropTargetView.swift in MobaAlt/Views/SFTP/:
    - SFTPDropTargetView: NSViewRepresentable. Takes service: SFTPBrowserService.
    - makeNSView: returns SFTPDropTargetNSView(service: service)
    - updateNSView: updates nsView.service

    Class SFTPDropTargetNSView: NSView, NSDraggingDestination:
    - var service: SFTPBrowserService
    - init(service:): calls super.init(frame: .zero); self.service = service; registerForDraggedTypes([.fileURL])
    - draggingEntered(_:) -> NSDragOperation: check pasteboard for fileURL items, return .copy if present else []
    - draggingUpdated(_:): return .copy (keep highlighting)
    - performDragOperation(_:) -> Bool:
      ```swift
      guard let urls = info.draggingPasteboard.readObjects(forClasses: [NSURL.self],
                                                             options: [.urlReadingFileURLsOnly: true]) as? [URL]
      else { return false }
      for url in urls {
          Task { @MainActor in
              try? await service.upload(localURL: url, toRemotePath: service.currentPath)
          }
      }
      return true
      ```
    - concludeDragOperation(_:): trigger listDirectory refresh after short delay
    - Render a semi-transparent overlay when dragging is active (draggingEntered shows overlay; draggingExited hides it): set @State var isDragTargeted: Bool in NSViewRepresentable Coordinator, or toggle a visual property on the NSView itself.

    3. Wrap the SFTPFileListView in a ZStack with SFTPDropTargetView as an invisible overlay (.opacity(0.001) so it still receives drag events but doesn't obscure the list):
       ```swift
       ZStack {
           SFTPFileListView(...)

               .allowsHitTesting(false)  // let clicks through to the list

       .onDrop(of: [.fileURL], delegate: SFTPSwiftDropDelegate(service: service))
       ```
       Actually, prefer the SwiftUI DropDelegate approach for the full area drop (simpler, reliable for file URLs in same-app drops) AND keep SFTPDropTargetNSView for Finder drops at the AppKit level.        Final approach: use only NSDraggingDestination (SFTPDropTargetNSView). Place it as a full-size background overlay via NSViewRepresentable with pointer-events passthrough. Do NOT use SwiftUI .onDrop for the same area to avoid double-handling.

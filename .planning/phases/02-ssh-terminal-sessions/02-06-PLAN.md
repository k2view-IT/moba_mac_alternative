  <how-to-verify>
You will need an SSH server to test against. Use localhost (if sshd is running: `sudo systemsetup -setremotelogin on`), a VM, or any accessible remote host.

**Core terminal (TERM-01, TERM-02, TERM-03, SSH-01):**
1. Build and run the app: Xcode -> Product -> Run (or `open MobaAlt.app`)
2. Double-click an SSH session in the sidebar -> a tab should appear and SSH should connect
3. Type `echo $TERM` -> should print `xterm-256color`
4. Type `vim /etc/hosts` -> vim should open with syntax highlighting, no garbled output
5. Open a second SSH session (double-click a second session) -> two tabs in the bar
6. Switch between tabs -> each tab maintains its own state (shell prompt/commands still visible)
7. Close a tab with the X button -> tab disappears; run `ps aux | grep ssh` to confirm no orphan

**Password auth (SSH-02, CRED-01):**
8. Create a session with authMethod = password. Connect. SSH should prompt for password in the terminal. Type password. Should authenticate.
9. Save the password to Keychain via the credential picker. Reconnect. Verify password is retrieved (check Keychain Access.app under login keychain for "com.mobaalt.MobaAlt").

**SSH key auth (SSH-02, CRED-02, CRED-03, CRED-04):**
10. Open KeyVaultView (toolbar key icon). Unlock vault with a master password.
11. Generate a new Ed25519 key pair (SSH-07). Add the public key to the server's authorized_keys.
12. Create a session with authMethod = privateKey, select the vault key. Connect. Should authenticate without password prompt.

**SSH config respected (SSH-03):**
13. Add a Host entry to `~/.ssh/config` (e.g., `Host testbox` with Hostname/User). Create a session using that hostname. Connect. Verify the config's settings are applied (ssh inherits them because only the hostname is passed when port=22 and username is empty).

**Agent forwarding (SSH-04):**
14. Run `ssh-add ~/.ssh/id_ed25519` in Terminal.app. In MobaAlt, enable agent forwarding in session settings. Connect. In the session, type `ssh-add -l` -> should list the key from the agent.

**Port forwarding (SSH-05, SSH-06):**
15. Add a local forwarding rule in the session editor Tunnels tab (e.g., local 8080 -> remoteHost:80). Connect. Run `curl -s http://localhost:8080` -> should reach the remote service.
16. Click the Tunnels toolbar button while connected -> ActiveTunnelsView should show the rule.

**Session logging (TERM-04):**
17. Connect. Type some commands. Disconnect (close tab). Check `~/Library/Application Support/MobaAlt/Logs/` -> a log file should exist with session output.

**Command snippets (TERM-05):**
18. Open the Snippets panel (toolbar icon). Add a snippet named "List files" with body `ls -la`. Connect to a session. Click "Send" next to the snippet -> `ls -la\n` should execute in the terminal.

**Report any issues found. Type "approved" if all critical flows work.**

From Research Pattern 6 (KeychainManager):
```swift
// Thread-safe actor; service identifier: "com.mobaalt.MobaAlt"
actor KeychainManager {
    func savePassword(_ password: String, for sessionId: UUID) throws
    func getPassword(for sessionId: UUID) throws -> String?
    func deletePassword(for sessionId: UUID) throws
    // updatePassword is private — called by savePassword on errSecDuplicateItem
}

enum KeychainError: Error {
    case operationFailed(OSStatus)
    case dataConversionFailed
}
```

From Research Pattern 7 (KeyVaultManager):
```swift
// CryptoKit.AES.GCM vault; salt persisted alongside vault
actor KeyVaultManager {
    // Vault lives at ~/Library/Application Support/MobaAlt/keyvault.enc
    // Salt lives at ~/Library/Application Support/MobaAlt/keyvault.salt
    init(directory: URL)   // for test isolation; default uses Application Support

    func unlock(masterPassword: String) throws
    func isUnlocked: Bool { get }
    func addKey(name: String, privateKeyData: Data) throws
    func getKey(name: String) throws -> Data
    func removeKey(name: String) throws
    func listKeyNames() throws -> [String]
}

enum VaultError: Error {
    case locked
    case wrongPassword
    case vaultCorrupted
    case keyNotFound(String)
}
```

From Pitfall 7 (deterministic key derivation):
- Salt generated once, persisted to keyvault.salt (NOT secret)
- Key derivation: HKDF<SHA256> with persistent salt + master password as input key material
- Vault does NOT need a separate "verify" record — decryption failure = wrong password
  IMPORTANT: Wrap AES.GCM.open in a do/catch and throw VaultError.wrongPassword on CryptoKitError

Create MobaAlt/Services/KeyVaultManager.swift as an `actor`. Import `CryptoKit` and `Foundation`.

Vault file layout:
- `keyvault.enc` — AES-GCM combined ciphertext (nonce + ciphertext + tag) of JSON-encoded `[String: Data]`
- `keyvault.salt` — 32 random bytes, generated once on first unlock/creation

Key derivation:
```swift
let keyData = HKDF<SHA256>.deriveKey(
    inputKeyMaterial: SymmetricKey(data: Data(masterPassword.utf8)),
    salt: salt,
    outputByteCount: 32
)
```

Vault initialization flow:
1. If `keyvault.salt` does not exist: generate 32 random bytes, write to salt file
2. Load salt, derive key from master password + salt
3. If `keyvault.enc` exists: try to decrypt; if decryption throws CryptoKitError → throw VaultError.wrongPassword
4. If `keyvault.enc` does not exist: vault is empty `[String: Data]()`, write encrypted empty vault

Implement `init(directory: URL)` for test isolation (same pattern as SessionStore in Phase 1). Add a static property `defaultDirectory` returning the Application Support/MobaAlt URL.

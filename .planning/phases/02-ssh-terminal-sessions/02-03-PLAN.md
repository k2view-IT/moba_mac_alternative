```swift
import Foundation

struct SSHArgumentBuilder {
    /// Builds argv for /usr/bin/ssh from an SSHConfig.
    /// Returns [String] suitable for LocalProcessTerminalView.startProcess(args:)
    static func build(from config: SSHConfig) -> [String]

    /// Returns the ControlMaster socket path for a session.
    /// Uses first 8 chars of UUID to stay under macOS 104-char socket limit.
    static func controlPath(for sessionId: UUID) -> String

    /// Returns the environment array (KEY=VALUE strings) for the SSH process.
    /// Always sets TERM=xterm-256color, LANG=en_US.UTF-8.
    /// Inherits SSH_AUTH_SOCK from parent process if present.
    static func environment(inheritingFrom base: [String: String] = ProcessInfo.processInfo.environment) -> [String]
}
```

**SSHConnection (MobaAlt/Services/SSHConnection.swift):**
`@Observable final class SSHConnection: LocalProcessTerminalViewDelegate`
This class creates the LocalProcessTerminalView and manages its lifecycle.

```swift
import SwiftTerm

enum SSHConnectionState { case connecting, connected, disconnected }

@Observable
final class SSHConnection: LocalProcessTerminalViewDelegate {
    let tabId: UUID
    let session: SessionDefinition
    private(set) var state: SSHConnectionState = .connecting
    var logWriter: SessionLogWriter?

    // The actual terminal NSView — created lazily, accessed from main thread
    private(set) var terminalView: LocalProcessTerminalView?

    func start()      // creates LocalProcessTerminalView, calls startProcess
    func terminate()  // calls process.terminate(), nils delegate

    // LocalProcessTerminalViewDelegate
    func processTerminated(_ source: LocalProcessTerminalView, exitCode: Int32?)
    func sizeChanged(source: LocalProcessTerminalView, newCols: Int, newRows: Int)
}
```

IMPORTANT: `LocalProcessTerminalView` must be created and manipulated on the main thread. Mark `start()` and `terminate()` with `@MainActor`. The `state` property is observed by SwiftUI views — mutations must occur on main actor.

For logging (TERM-04): In `SSHConnection`, subclass `LocalProcessTerminalView` as `LoggingTerminalView` that overrides `feed(byteArray:)` to call `super.feed(byteArray:)` then `logWriter?.write(byteArray)` — this avoids modifying SwiftTerm internals.

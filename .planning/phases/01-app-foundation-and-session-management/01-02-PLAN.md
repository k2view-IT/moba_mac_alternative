- `.onDrop(of: [UTType.text], delegate: FolderDropDelegate(targetFolderId: folder.id, library: sessionLibrary))` on the label

**SessionEditorSheet.swift**:
- Presented as `.sheet(isPresented:)` from SidebarView and context menu actions
- Takes `session: SessionDefinition?` (nil = creating new), `targetFolderId: UUID?`
- Local `@State var draft: SessionDefinition` initialized from passed session or a new blank SSH session
- `TabView(selection: $selectedTab)` with two tabs: "Basic" and "Advanced"
- A "Wizard" button in the sheet toolbar that switches to `SessionWizardView` (presented as another sheet or inline replacement)
- Bottom toolbar: "Cancel" (dismiss) and "Save" (validate + call sessionLibrary.addSession or updateSession)
- Title: "New Session" or "Edit Session"

**SessionEditorBasicTab.swift**:
- Fields:
  - "Name" TextField bound to `draft.name`
  - "Type" Picker (.segmented or .menu) for SSH / RDP / VNC — changing type reinitializes `draft.protocolConfig` with defaults
  - "Hostname" TextField bound to protocol-specific hostname field; onChange: if `draft.name` is empty OR matches the previous hostname (auto-filled), update `draft.name = newHostname` — this is the auto-fill behavior
  - "Port" TextField bound to protocol-specific port (numeric, initialized to 22 / 3389 / 5900 based on type)
  - "Username" TextField (SSH and RDP only; not shown for VNC)
  - "Auth Method" (SSH only): Picker with cases Password / Private Key / SSH Agent
  - "Password" SecureField (SSH + RDP + VNC): shows checkbox "Save to Keychain" defaulting to true; actual Keychain write deferred to Phase 2 — in Phase 1 just capture the intent in a local `@State var saveToKeychain: Bool`
- Form layout using `Form { Section("Connection") { ... } Section("Authentication") { ... } }`
- `.formStyle(.grouped)` for macOS native appearance

**SessionEditorAdvancedTab.swift**:
- "Notes" TextEditor with placeholder text "Optional notes about this session..." — multiline, min height 80pt
- "Folder" Picker showing all folders (flat list with indentation for depth) + "Root (no folder)" option — updates `draft.folderId`
- (Stub placeholders for future fields): empty sections "Port Forwarding", "Logging" with `Text("Available in Phase 2").foregroundStyle(.secondary)`

**SessionWizardView.swift**:
- Multi-step guided entry: 4 steps
  - Step 1 "Type": Picker SSH / RDP / VNC with large icons and brief description per type
  - Step 2 "Connection": Hostname, Port, Username (same auto-fill logic as basic tab)
  - Step 3 "Authentication": Auth method for SSH (password/key/agent); password + save-to-keychain for RDP/VNC
  - Step 4 "Options": Name override, Notes, Folder assignment
- Navigation: "Back" and "Next/Finish" buttons; step indicator dots at top
- On "Finish": writes back to `draft` in parent sheet and dismisses wizard

**PreferencesView.swift**:
- Opens via Settings scene (`Cmd+,`)
- "General" section:
  - "Sidebar Density" Picker with options Compact / Comfortable — writes to `@AppStorage("sidebarDensity")`
  - "Sidebar Toggle Shortcut" Label showing "⌘⇧L" (read-only display)
- Use `.frame(width: 400, height: 200)` for window size
- Standard macOS preferences appearance: `Form { }.formStyle(.grouped)`

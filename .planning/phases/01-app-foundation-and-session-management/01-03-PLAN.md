.mxtsessions format (from 01-RESEARCH.md):
- Encoding: Windows-1252 (CP1252), fallback UTF-8
- Sections: [Bookmarks] (root), [Bookmarks_1], [Bookmarks_2] (subfolders)
- SubRep key: empty = root, "FolderName" or "Parent\\Child" for nested
- Session line: `SessionName=#IconNum#Group1#Group2#TabMode#Comments#TabColor`
- Group1 is %-delimited; field[0] = type code (0=SSH, 4=RDP, 5=VNC)
- SSH fields: type, host, port, user (indices 0-3); X11=field[5](-1=on); privkey=field[14]
- RDP fields: type, host, port (indices 0-2)
- VNC fields: type, host, port (indices 0-2)
- Special encoding: __PTVIRG__=;  __DBLQUO__="  __PIPE__=|  __DIEZE__=#  __PERCENT__=%  _CurrentDrive_=C:
- Parse flexibly: use defaults for missing fields; skip malformed lines with logged warning

**MXTSessionsParser.swift**:

```swift
struct MXTParseResult {
    var folders: [SessionFolder]   // all parsed folders (parentId set by SubRep path)
    var sessions: [(folderId: UUID?, session: SessionDefinition)]
    var errors: [String]           // malformed line descriptions
}

struct MXTSessionsParser {
    func parse(data: Data) throws -> MXTParseResult
}
```

Implementation:
1. Decode data as Windows-1252: `String(data: data, encoding: .windowsCP1252)` — if nil, try `.utf8`; if both nil, throw `ParseError.invalidEncoding`.
2. Normalize line endings: replace `\r\n` and `\r` with `\n`.
3. Split into INI sections at `[Bookmarks` lines. Track section name.
4. For each section:
   - Read `SubRep=` line to get folder path (e.g., `"Production\\DB"`). Empty = root.
   - Build folder hierarchy from SubRep paths. Use a dictionary `[String: UUID]` mapping path -> folder ID to avoid duplicates.
   - For folder paths like `"A\\B"`: ensure folder "A" exists (create if not), then create "B" with parentId = A's UUID.
5. For each session line (`Name=Value` where Value starts with `#`):
   - Split value by `#` into [iconNum, group1, group2, tabMode, comments, tabColor].
   - Split group1 by `%` into fields array.
   - `typeCode = Int(fields[0]) ?? -1`
   - Build `SessionDefinition` based on typeCode:
     - 0 (SSH): SSHConfig(hostname: fields[safe:1], port: Int(fields[safe:2]) ?? 22, username: fields[safe:3] ?? "")
     - 4 (RDP): RDPConfig(hostname: fields[safe:1], port: Int(fields[safe:2]) ?? 3389)
     - 5 (VNC): VNCConfig(hostname: fields[safe:1], port: Int(fields[safe:2]) ?? 5900)
     - Other: log to errors array, skip.
   - Decode special sequences in ALL string fields: replace __PTVIRG__ -> ";", __DBLQUO__ -> `"`, __PIPE__ -> "|", __DIEZE__ -> "#", __PERCENT__ -> "%", _CurrentDrive_ -> "C:".
   - Session name = key part (before `=`), also decode special sequences.
   - sortOrder = index within section.
6. Return MXTParseResult.

Use `Array.subscript(safe:)` extension that returns nil for out-of-bounds to handle missing fields gracefully.

**MXTSessionsWriter.swift**:

Serialize sessions + folders back to .mxtsessions INI format.
- Build SubRep paths by walking folder parentId chain.
- Group sessions by folderId.
- Write root section [Bookmarks] with SubRep= (empty).
- Write one [Bookmarks_N] section per folder with SubRep=path.
- Session lines: encode special sequences (reverse of parser), write `name=#109#typeCode%host%port%user%...#...#0#0#0#0#` format.
- Encode to Windows-1252 data. If encoding fails, fallback to UTF-8.
- NEVER write password fields.

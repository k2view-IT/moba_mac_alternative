Follow the exact interface contracts defined in the `<interfaces>` block above. Key implementation rules:

**ConnectionProtocol.swift**
- `enum ConnectionProtocol: Codable, Hashable` with cases .ssh(SSHConfig), .rdp(RDPConfig), .vnc(VNCConfig)
- Custom `CodingKey`-based encode/decode so the JSON shape is `{"type":"ssh","config":{...}}` — required for forward-compatibility in Phases 2-4
- Computed properties: `protocolName: String`, `hostname: String`, `port: Int`

**SessionDefinition.swift**
- `struct SessionDefinition: Identifiable, Codable, Hashable`
- Fields per interface block. `id` is `let UUID` (never mutated). `folderId: UUID?` (nil = root).
- `sortOrder: Int` — MUST be explicit. Never rely on array index for ordering.
- `notes: String` — defaults to "" (used in HTML export and editor Advanced tab).
- Passwords are NEVER stored here. Comment: "Credential stored in Keychain keyed by session.id.uuidString".

**SessionFolder.swift**
- `struct SessionFolder: Identifiable, Codable, Hashable`
- `parentId: UUID?` (nil = root-level folder), `sortOrder: Int`, `isExpanded: Bool = true`

**SessionLibrary.swift**
- `@Observable final class SessionLibrary`
- `var sessions: [SessionDefinition]` and `var folders: [SessionFolder]` are the source of truth
- `sessions(inFolder:)` returns sessions where `folderId == folderId` sorted by `sortOrder` ascending
- `subfolders(of:)` returns folders where `parentId == parentId` sorted by `sortOrder` ascending
- `search(query:)` returns sessions where `session.name.localizedCaseInsensitiveContains(query) || hostname.localizedCaseInsensitiveContains(query)`. Returns all sessions when query is empty.
- Mutation methods (addSession, updateSession, deleteSession, addFolder, updateFolder, deleteFolder) update the arrays and call a stored `onMutation: () async -> Void` closure for persistence. Default no-op closure.
- When deleting a folder: also delete all child sessions (sessions.folderId == folder.id) and recursively delete subfolders.

**SessionStore.swift**
- `actor SessionStore`
- `init()` computes `appSupportURL` as `FileManager.default.urls(for:.applicationSupportDirectory, in:.userDomainMask).first!.appendingPathComponent("MobaAlt")`; creates directory if needed.
- `save(sessions:folders:)`: write backup copy of existing files (append ".backup" extension, using `copyItem(at:to:)`); then `try encoder.encode(sessions).write(to: sessionsURL, options: .atomic)`; then encode + write folders. Use `JSONEncoder` with `.prettyPrinted` and `.sortedKeys`.
- `load()`: if files don't exist, return ([], []). Decode both files; on decode error, attempt loading from backup; on backup error, return ([], []) with a logged warning.
- Initialize `SessionLibrary` from the store at app startup: in MobaAltApp.swift, create `SessionStore` and `SessionLibrary`, call `store.load()`, populate library, wire `library.onMutation = { try? await store.save(...) }`.

**AtomicFileWriter.swift**
- Simple `func atomicWrite(_ data: Data, to url: URL) throws` that calls `data.write(to: url, options: .atomic)`. Exists for semantic clarity and future extension (encryption in Phase 2).
